Bouton Charte

Le bouton Charte met le message que vous rédigez aux couleurs de Le Froid Pecomark : police Century Gothic, 10 pt, bleu foncé.

Utilisation

Rédigez votre message, puis cliquez sur Charte dans le ruban du message. Dans le nouvel Outlook, le bouton peut se trouver sous Applications.

Votre signature et le message auquel vous répondez ne sont pas modifiés. Vous pouvez cliquer plusieurs fois, le résultat reste le même.

Signature

Dans le nouvel Outlook et Outlook sur le web, le bouton ajoute aussi votre signature aux messages qui n'en ont pas, par exemple un brouillon préparé à l'avance.

Pour cela, il doit d'abord la connaître : cliquez une fois sur Charte dans un nouveau message où Outlook a déjà inséré votre signature. Le bouton la mémorise sur votre poste et la met à jour à chaque clic sur un message signé.
