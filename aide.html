Bouton Charte

Le bouton Charte met le message que vous rédigez aux couleurs de Le Froid Pecomark : police Century Gothic, 10 pt, bleu foncé.

Utilisation

Rédigez votre message, puis cliquez sur Charte dans le ruban du message. Dans le nouvel Outlook, le bouton peut se trouver sous Applications.

Votre signature et le message auquel vous répondez ne sont pas modifiés. Vous pouvez cliquer plusieurs fois, le résultat reste le même.

Un problème ?

Contactez le Service Informatique.
